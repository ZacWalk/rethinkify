01/05

Photos & video

I take a lot of photos and videos. In 1998 I wrote my own PC photo management software, ArtMate, a tiny thumbnail browser. It was fast and minimal because life is too short for slow software. It grew into ImageWalker, shareware that turned out to be surprisingly popular, and ImageWalker grew into Diffractor.

Diffractor is free, local-only and fast, with Direct3D and SIMD doing the heavy lifting. It reads RAW, puts photos on a map from their GPS, spots duplicates even after they have been resized or re-encoded, and speaks 14 languages. It is open source too. Twenty-odd years in, I am still not sure it is finished.

02/05

AI & machine learning

My first brush with machine learning came at a Microsoft hackathon around 2015, while I was working on Skype. The idea was a video call that worked over a 2G network, at about 10 kbit/s. At that speed all you can send is a blurry mess, so low-ban tracks the landmarks of your face and sends those along too: you can at least see whether someone is smiling. I demoed it to Skype's head of design, who wore all black and really looked the part. Nothing came of it, but I still poke at it; these days a learned autoencoder runs beside a classic codec on the same webcam frame.

I later wrote libcmlp, a multi-layer perceptron. It tells a sock from a shirt in Fashion-MNIST about 89.9% of the time, about as well as any perceptron, and it can train a reinforcement learner too. Then, having been a compiler engineer for a while, I wondered if I could compile an LLM to run on the CPU. nnc is that compiler. It writes AVX2 machine code for the model as it loads, and runs Gemma 3 1B at about 28 tokens a second on my PC. It is an embeddable library, if you want to add CPU LLM support to your own app.

03/05

Markets & money

I have always found the financial world fascinating. In 2007 I worked at Merrill Lynch, the year it lost more than $20 billion on subprime mortgages. Not my fault. I invest in technology stocks myself and publish my research at Alpha Galactica. It is not financial advice. I also did experiments with reinforcement learning and trading in price-app. Sadly, any edge is offset by retail trading fees.

I have a few components to support this. libcfindata fetches the data from SEC filings and FRED. spike-db stores market data and reads it back at around 80 million records a second.

04/05

Compilers & emulators

I learned to program on a Commodore 64. I think it is a machine simple enough for anyone to understand how computers work. Turbo 8bit is my educational C64 emulator in the browser: type BASIC into a live machine, single-step 6502 assembly, or watch the bus traffic as it boots. lib8bit is the same emulator as a C++20 library.

When Microsoft open-sourced MS-DOS 4.0, I wanted to build it myself, but that needs the original 16-bit tools, so I wrote libdos, a little DOS emulator to run them. That allowed me to create dos4z, a version of DOS 4.0 with bug fixes and larger disk support. It allows my IBM 5150 to boot and work well with my CF hard drive adapter.

In 2022 I wrote the proposal for Microsoft to back a GNU toolchain for Windows on Arm. It was accepted, and I worked with Linaro's compiler team and other open-source contributors to add support for that backend.

In that role I did a lot of low-level training inside Microsoft. vector-experiments started life as that course: hand-written AVX2 beats a plain loop by about 34 times.

Later I moved to work on Rust at Microsoft, where Oxidizer is the framework behind some of its most critical services. One of my first Rust experiments was rust-http-sys, a wrapper for the Windows kernel's web server, and one of our Rust experts said it looked like a C++ developer trying to write Rust. Fair enough.

05/05

Win32 apps

I grew up in the glory days of Win32, when an app was one small, fast .exe, and I have been writing them ever since. Around 2000 my employer still supported Windows 95, whose task manager really was basic, so I wrote my own improved version, system-stuff. Around that time I also wrote ergo-active with my London neighbour, a Swedish furniture designer. It reminds you to take a break if you have been using the computer too long.

Then I spent a few years on the other side of the fence, owning the native code in the Teams desktop app, which ran on Electron. I managed that team but did make a few Electron contributions: I swapped Electron's WTL file dialogs for plain Win32, extended its tracing so we could see where the memory went, and wrote electron-bench, which shows that the IPC path everyone argues about barely changes latency, but changes main-process CPU by more than 20 times. My longest-lasting contribution is a “temporary” fix to Chromium's build from 2018. It is still in Electron today, FIXME and all.

I have my own C++ layer for small native apps, platform-h, built with dd, a PowerShell script that thinks it is a package manager. The rethinkify editor is my text editor, with GitHub Copilot in a side panel, and potato is a web browser I wrote to learn CSS: probably the worst in the world, but it shows Wikipedia from 2015 nicely. And a few games: zpilot began in 1995 as a Turbo C++ game for DOS, and Stunt Car Racer, which I loved on my C64, is the Amiga code rewritten from fixed-point to floating-point maths. That it ever ran in fixed-point shows how amazing those programmers were.
